TODO List App 

A simple TODO list app built with Next.js, TypeScript, and Tailwind CSS. It allows users to:

- Add, edit, delete tasks
- Toggle task completion
- Search tasks by title
- Sort tasks by priority, status, or latest
- Mark tasks with recurrence (daily, weekly, monthly)

---

Installation

1. Clone the repository or extract your project folder 

```bash
git clone https://github.com/DilshanLK/TODO-App.git
cd todo-app
```

2. Install dependencies

 ```bash
npm install
```

3. Running the App

```bash
npm run dev
```

Then open your browser and visit: http://localhost:3000
